Tidy data

What makes data tidy?

  1. Each variable is a column
  2. Each observation is a row
  3. Each value is a cell

Tidy data is the shape dplyr and ggplot2 expect. Most of your time cleaning data goes into getting it there.

Untidy: one column per day

clinic day_1 day_2 day_3
clinical lab 12 18 25
emergency dept 4 9 7

“Day” is a variable, but its values are stuck in the column names. (The fix is pivot_longer(), covered with reshaping.)

Tidy: one row per clinic-day

clinic day tests
clinical lab 1 12
clinical lab 2 18
clinical lab 3 25
emergency dept 1 4
… … …

The pipe

Read |> as “and then”

covid |>
  filter(result == "positive") |>
  count(clinic_name)

Take covid, and then keep the positive tests, and then count them by clinic.

Without the pipe, the same code reads inside-out:

count(filter(covid, result == "positive"), clinic_name)

Shortcut: Cmd/Ctrl + Shift + M types |>. You may also see %>%. It works the same way for our purposes.

Multiple conditions

# both must be true: comma (or &)
covid |> filter(result == "positive", age >= 18)

# either can be true: |
covid |> filter(clinic_name == "nicu" | clinic_name == "picu")

# match any value in a list: %in%
covid |> filter(clinic_name %in% c("nicu", "picu"))

# not equal
covid |> filter(result != "invalid")

Warning

= assigns, == compares. filter(result = "positive") is an error.

select() helpers

covid |> select(subject_id:gender)      # a range
covid |> select(-fake_first_name, -fake_last_name)  # drop
covid |> select(starts_with("demo"))   # by name pattern
covid |> select(ends_with("_tat"))
covid |> select(where(is.numeric))     # by type

summarize(): collapse to one row

covid |>
  summarize(
    n_tests      = n(),
    mean_age     = mean(age),
    pct_positive = mean(result == "positive") * 100
  )
# A tibble: 1 × 3
  n_tests mean_age pct_positive
    <int>    <dbl>        <dbl>
1   15524     14.2         5.57

Why does mean(result == "positive") give a proportion? TRUE counts as 1 and FALSE as 0.

group_by() + summarize()

covid |>
  group_by(drive_thru_ind) |>
  summarize(
    n_tests      = n(),
    pct_positive = mean(result == "positive") * 100
  )
# A tibble: 2 × 3
  drive_thru_ind n_tests pct_positive
           <int>   <int>        <dbl>
1              0    7537         5.12
2              1    7987         6.00

One row per group. This is the workhorse of descriptive epidemiology.

Missing values

covid |>
  summarize(mean_ct = mean(ct_result))
# A tibble: 1 × 1
  mean_ct
    <dbl>
1      NA
covid |>
  summarize(mean_ct = mean(ct_result, na.rm = TRUE))
# A tibble: 1 × 1
  mean_ct
    <dbl>
1    44.1

One NA makes the whole mean NA. Use na.rm = TRUE, and think about why values are missing.

Putting it together

A full pipeline

Positivity by gender among patients, excluding invalid tests:

covid |>
  filter(demo_group == "patient", result != "invalid") |>
  group_by(gender) |>
  summarize(
    n = n(),
    pct_positive = round(mean(result == "positive") * 100, 1)
  )
# A tibble: 2 × 3
  gender     n pct_positive
  <chr>  <int>        <dbl>

Recap

Verb Works on Does
filter() rows keeps rows that meet a condition
arrange() rows sorts rows
select() columns keeps or drops columns
mutate() columns adds or changes columns
summarize() groups collapses to one row per group
count() groups shortcut for counting
