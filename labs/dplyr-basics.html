Lab: Data wrangling with dplyr

COVID-19 testing at a children’s hospital

NoteHow this lab works

Everything runs in your browser, so there’s nothing to install. Fill in each ______ and click Run Code. Each exercise lists the exact column names and values to use, so you don’t need the codebook. The box tells you if you got it right. Stuck? Click Show Hint; still stuck, Show Solution.

The first time you click Run, R takes a few seconds to load.

The data

covid holds 15,524 COVID-19 tests from the first 107 days of the pandemic at the Children’s Hospital of Philadelphia (from the medicaldata package). Names in the data are fake. Some of the columns:

Column Meaning
subject_id Person tested
gender Gender
age Age in years
pan_day Day of the pandemic the test was collected (day 1 = start of data)
clinic_name Where the sample was collected
result "positive", "negative", or "invalid"
demo_group "patient", "client", "misc adult", "other adult", "unidentified"
drive_thru_ind 1 = collected at a drive-through site, 0 = not
ct_result PCR cycle threshold (45 = virus not detected)

Part 1: Is it tidy?

Remember the three rules of tidy data: each variable is a column, each observation is a row, and each value is a cell.

TipQuestion: What is one row of covid? Think, then click to check.

One row is one test. Some people were tested more than once, so one row is not one person. That matters when you count: nrow(covid) counts tests, not people.

TipQuestion: Imagine a table with one row per clinic and a separate column for each pandemic day’s test count. Is that tidy?

No. “Day” is a variable, but in that table its values are spread across column names. The fix for that shape is pivot_longer(), covered with reshaping.

Part 2: Working with rows

Exercise 1: filter()

Keep only the positive tests.

Use: column result · value "positive"

result is a character column, so the value goes in quotes: "positive".

covid |>
  filter(result == "positive")

There are 865 positive tests.

Exercise 2: filter() with two conditions

Keep positive tests from people who are 18 or older.

Use: column result · value "positive" · column age · value 18 · operator >=

Separating conditions with a comma inside filter() means both must be true. Use >= for “greater than or equal to.”

covid |>
  filter(result == "positive", age >= 18)

Exercise 3: arrange()

Sort the tests from oldest to youngest person. Look at the top of the result.

Use: column age · function desc()

arrange() sorts smallest-to-largest by default. Wrap the column in desc() to reverse it.

covid |>
  select(subject_id, age, demo_group) |>
  arrange(desc(age))
ImportantThink about it: what’s wrong with the top rows?

The oldest “person” is 138, and several are 119. Those ages are almost certainly data entry errors or placeholder values. Real data always needs a sanity check before analysis. Sorting is one of the quickest ways to find problems.

Part 3: Working with columns

Exercise 4: select()

Keep only four columns, in this order.

Use: columns subject_id, age, clinic_name, result

List the column names inside select(), separated by commas. No quotes needed.

covid |>
  select(subject_id, age, clinic_name, result)

Exercise 5: mutate()

Add a new column that is age in months.

Use: new column age_months · existing column age · multiply by 12

There are 12 months in a year. Columns can be used in arithmetic: age * 2.

covid |>
  mutate(age_months = age * 12) |>
  select(subject_id, age, age_months)

Part 4: Summarizing

Exercise 6: count()

How many tests came from each clinic? Show the largest first.

Use: column clinic_name · argument sort = TRUE

count() has an argument sort. Set it to TRUE.

covid |>
  count(clinic_name, sort = TRUE)

Exercise 7: group_by() + summarize()

Were drive-through tests more likely to be positive? Compute the number of tests and the percent positive for drive-through vs. other tests.

Use: group by column drive_thru_ind (1 = drive-through, 0 = not) · summary columns n and pct_positive

Group by the column that marks drive-through tests.

Why does mean(result == "positive") work? result == "positive" gives TRUE/FALSE, which R treats as 1/0. The mean of 1s and 0s is a proportion.

covid |>
  group_by(drive_thru_ind) |>
  summarize(
    n = n(),
    pct_positive = mean(result == "positive") * 100
  )

Exercise 8: your turn, from scratch

Find the median age for each demographic group.

Use: group by column demo_group · column age · function median() · summary column median_age

Same pattern as Exercise 7: group_by() then summarize(). Use median(age).

covid |>
  group_by(demo_group) |>
  summarize(median_age = median(age))

Part 5: Put it all together

Exercise 9

Among patients only, and excluding invalid tests, what percent of tests were positive for each gender? Round to 1 decimal place.

Use:

  • keep: column demo_group · value "patient"
  • drop: column result · value "invalid" · operator !=
  • group by: column gender
  • summary columns: n and pct_positive · positive value "positive" · round(..., 1)

Two conditions in filter(): demo_group == "patient" and result != "invalid" (!= means “not equal to”).

For the percent, reuse mean(result == "positive") * 100 from Exercise 7.

covid |>
  filter(demo_group == "patient", result != "invalid") |>
  group_by(gender) |>
  summarize(
    n = n(),
    pct_positive = round(mean(result == "positive") * 100, 1)
  )

Wrap-up

You used the five core dplyr verbs today:

Verb Does what to the data
filter() keeps rows that meet a condition
arrange() sorts rows
select() keeps columns
mutate() adds or changes columns
group_by() + summarize() collapses each group to one row

The assignment for this topic practices these verbs in RStudio. The cheat sheet has all the syntax on one page.
